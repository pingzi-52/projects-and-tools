# Pixel Top-down Farm Tileset (16x16)
108 tiles and sprites: 12 ground, 5 soil, 7 water, 24 crop frames (6 crops x 4 growth stages), 7 fences/gates, 11 props, 15 nature, 5 tools, 14 items, 8 animal frames.
Files: PNG/native (16x16), PNG/x4 (64x64), spritesheet.png/.json, tileset.png (terrain), sample_scene.png.
Engines: Unity/Godot/GameMaker - set Filter = Point (no filter), Compression = None. Crops/props are transparent; place on soil/grass tiles.
