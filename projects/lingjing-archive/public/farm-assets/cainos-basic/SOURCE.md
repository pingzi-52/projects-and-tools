redistribution or resale of the asset pack. This record is a summary, not a new

PNG files are copied unchanged. JSON frame metadata is converted from the
author's TextureImporter metadata in the included Unity package: Unity's
bottom-left Y is converted to PNG's top-left Y. Tree upper/lower frames are
combined only as rendering rectangles; artwork is not regenerated or recolored.

The free pack does not provide a complete farm environment. This preview uses
grass, flowers, three trees, bushes, stone paving, rocks, barrels and crates only.
Water, farmhouse, complete wood fence/gate, dirt path and seasonal farm assets
are not represented as supplied by this free pack.
