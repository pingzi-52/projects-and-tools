# Original item icons v1 · 2026-10-15

Generated with built-in image_gen for this original game's warm woodland-farm style. No purchased art, Stardew Valley sprites or restricted third-party reference was used. Original full PNG preserved, project file is a byte-for-byte copy.

Source: exec-cc89e9b4-1a23-45e2-a579-bc65746206bd.png under this conversation's Codex generated_images directory. Prompt retained in prompt.txt.

Actual PNG is 1268×1241 RGBA, transparent corner alpha0. Exactly25 frames: two tools, coin, 11 crops and 11 seed packets. Native high-resolution pixel-style source, NOT certified native16/32px or finite palette. Crops and folded paper packets have consistent identities; game crop IDs/names/rules unchanged.

Cells are not assumed to be a uniform generated grid: each alpha region was measured independently, added2px transparent margin, and centered on a square source canvas in TexturePacker JSON. Display HUD24px, selected16px, menu32px with nearest sampling. PNG pixels unmodified. icon-bounds.json retains raw measured regions.

Runtime missing frames use the existing placeholder textures without editing placeholderAssets.ts. Empty slots show the wooden frame without the old gray placeholder square.

Sound is separate: FarmAudio generates brief filtered-noise/oscillator cues and low wind/rain using Web Audio. There are no downloaded recordings, samples, music or external sound licenses in this addition. Subjective listening review is still required; automated graph/energy checks are not listening.
