# 农场局部花草层 · 第二轮

范围：耕地两侧四个小簇和附近树下细节，未重做地图。全部使用Cainos原图，未下载或生成新包。

实现：farmDetails.ts根据静态地图产生48个确定性装饰格，避开床旁、出生点、主通道和所有非草地格。farmEnvironment放置173个小型花草图元，使用确定性错位与疏密变化；根据源帧实际尺寸限制在单格内。装饰不创建物理体，位于耕地及作物下面。FarmScene创建装饰层，并在耕地状态变化时通知隐藏对应格装饰。种植规则、存档、原地图、placeholderAssets不变。

验证：最终类型检查和构建通过；13文件187测试通过（新增4项布局保护）。Chrome实机查到48装饰格、无物理体，所有装饰bounds均不越格。独立新游戏中真实鼠标开垦12_8后，该格所有装饰visible=false且耕地覆盖存在。初次测试受热更新及旧v1存档无工具状态影响，另一次方向键导致目标漂到13_8；稳定测试位置并新游戏后验收通过。没有把这些测试状态误报为装饰失效，也未修改已有存档格式。

截图：docs/screenshots/farm-local-details.png，来自真实画布，包含测试开垦格。预览：http://127.0.0.1:5175/index.html 。用户日常浏览器存档未读取。
