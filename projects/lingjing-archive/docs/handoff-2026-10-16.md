## 在家恢复开发

使用能访问该私有仓库的 GitHub 账号。先安装 Git 和 Node.js；本机已使用 Node **24.16.0**、npm **11.13.0**，建议在家使用同一主版本，并保留仓库内 `package-lock.json`。

```bash
git clone https://github.com/pingzi-52/lingjing-farm.git
cd lingjing-farm
npm ci
npm run dev -- --host 127.0.0.1 --port 5175 --strictPort
```

打开 [游戏入口](http://127.0.0.1:5175/index.html)。独立美术预览是 [农场预览](http://127.0.0.1:5175/showcase.html?style=cainos-farm) 和 [农舍预览](http://127.0.0.1:5175/showcase.html?style=cainos-home)。这些是本机服务地址，必须先运行开发命令。

不方便配置 Git 时，登录私有仓库页面，选择 **Code → Download ZIP**，解压后执行 `npm ci` 和上述启动命令。ZIP包含全部开发文件、素材和文档，但不包含Git历史；后续需要提交代码时仍建议使用Git克隆。

`--strictPort` 会在 5175 被占用时报错，避免静默换端口造成「存档不见了」的误解。停止占用该端口的相关开发服务后再运行即可。项目不依赖原电脑盘符、临时目录或外部脚本，不需要 `.env`、API key、后台数据库或账号服务。依赖使用 `npm ci` 按锁文件恢复，不需要上传或复制 `node_modules/`。

验证命令：

```bash
npm test
npm run build
```

2026-10-16 上传前重新通过 **39 文件、657 项测试**与 TypeScript/Vite 构建；另从Git历史备份全新克隆，在无旧依赖的目录成功执行 `npm ci`，再次通过657测试和72模块构建，确认源树与素材完整。在家首次启动仍应实际试玩，不能以旧测试记录代替新机器运行确认。

## 最短试玩路线

1. 进入农场，在田边禾木旁按 E 接取委托，领 3 颗当季种子。选择工具开垦、播种、浇水。
2. 沿田地南侧横路向西进入林缘森林，找到岚接取采集委托；靠近资源按 E，每天 9 个点各采一次。
3. 沿原路回农场，再向东进入溪桥镇，找阿榆接修缮委托。L 查看区域和任务；K 制作、吃饭。
4. 回农舍睡觉推进日期并恢复体力，次日再采。完成两位新居民委托后制作提灯；作物成熟后交付禾木。

WASD/方向键移动，E 交互，1–8 选快捷栏，左键使用，I 背包，B 集市，Q 农场手记，L 区域手记，K 制作，M 声音，T 保存回标题，Esc 关闭菜单。屋内从门口正常出屋后再沿路去其他区域。

## 开发进度与个人游玩档是两件事

源码、素材、文档与测试进入 Git 仓库；**个人游玩档保存在浏览器 localStorage，不会随 GitHub 克隆自动同步到家里**。本轮不读取用户浏览器、不上传浏览器 profile，也不擅自上传个人存档。

如果需要把原电脑的游玩进度一起带走，需要另行明确导出并在新浏览器恢复；本版没有云存档或账号同步，也没有通用导入导出界面。应先保存好原始数据，不能通过覆盖浏览器目录迁移。端口、协议、主机名属于存储 origin：`localhost:5175`、`127.0.0.1:5175` 与其他端口彼此独立，即便在同一电脑也可能看到不同存档。固定 `http://127.0.0.1:5175` 便于保持一致，但不能实现跨电脑同步。

刷新后从农场继续，当前区域和精确角色位置尚不持久化，这不代表金币/耕地/探索进度丢失。
