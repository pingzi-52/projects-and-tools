# 小型测试版：任务与采集引导（2026-10-19）

本轮打磨已经存在的种田、采集与委托流程。沿用已接受的像素素材与自然步行连接，不添加传送、新任务或持久化字段。

## 玩家可见变化

- 禾木、岚、阿榆共用居民标记：远处 `!` 表示可以接取，`?` 表示随身材料齐了；走近后显示 E 交谈。进行中或完成的委托不会继续显示远处接取标记。
- 农场保留首份收成追踪；森林、小镇新增当前委托追踪，包括准确材料数量和下一步。森林另显示今日已采数量与睡觉刷新提示。
- L 手记显示三区方向、当前位置、三张委托卡。状态区分尚未接取、进行中、材料齐了、已完成；只有关闭按钮，所有接取和交付仍需找到居民。
- 附近未采资源显示浅金色四角提示。E、文字和高亮使用同一个目标：居民优先，其次附近未采点，再退回已采点的明日提示。不会被更近的已采点挡住可采点。
- 任务只统计随身背包，放进木箱的材料不计入；出售、存箱或制作消耗后，提示重新计算。首份收成继续使用接取时锁定的作物。
- 保留旧田覆盖商人全部候选位置时的 Q 便笺回退，HUD不再让玩家寻找不存在的驻点人物。

“材料齐了”仅表示任务材料达到要求，正式交付仍由原有事务校验金币上限与保存结果。只查看提示或手记不会接任务、扣物品、发报酬或写存档。

- 接入 FarmScene、ExplorationScene、MerchantResident、TravelMenu 与一份局部样式。
- 两份测试新增23例。领域层、GameSession、存档格式、原地图、原PNG、placeholderAssets均未修改；人物等比缩放与原黄框尺寸保留。后台黄框只增加不可见判断，位置计算不变。

标记与资源角标在菜单、后台和过图时隐藏；场景关闭显式销毁。L卡片内容独立滚动，关闭按钮保持在固定页头。

1. 向禾木领取种子，L出现锁定萝卜 `0/1`。
2. 沿西路进入森林，实际采集三处蘑菇，从 `1/3`、`2/3` 到 `3/3`，体力100降至94，今日采集3/9。
3. 在岚旁实际接取和交付，先出现材料齐标记，交付后金币500→580、蘑菇3→0、任务变已完成，领取按钮消失。
4. 走森林→农场→小镇，在阿榆处接取修缮委托，材料为枯枝0/6、溪石0/4。
5. 刷新并继续：三张卡与刷新前逐项一致，森林完成和当天3/9保留，金币580、体力94保留。区域按原合同回到农场。
6. 实测手记480×339.5，内容260px无溢出，只有一个关闭按钮。L打开时移动按键未穿透；本轮捕获的浏览器错误日志为空。
