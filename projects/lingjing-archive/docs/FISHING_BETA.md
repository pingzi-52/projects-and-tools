# 池畔钓鱼测试版

2026-10-20；本地实现与测试通过，未提交、推送或对外发布。

## 怎么玩

沿农场中间横路向东，再走到东南池塘岸边。出现F提示时按F下竿；岸边备有鱼竿，不必先购买。等待浮标下沉，出现“咬钩了”后按F/空格或点“提竿”；收线阶段在指针进入绿区时操作3次。错过咬钩、5次失误或20秒超时鱼会逃走。按住按键不会连发，回合还有250ms去抖。

鱼上岸后点“收好鱼获”，真正保存后才扣4体力；可立即再钓，也可关闭。取消或失败免费，尚未收好的鱼不会保存。保存失败不会扣鱼获或体力，可重试收好。Tab切按钮、Space操作当前按钮、Esc退出均保留。

鱼获：银鳞鲫24金、日纹鲤40金；可堆叠99、放背包/木箱、在背包出售。初版没有鱼竿升级/饵料/图鉴/委托和天气专属鱼，平衡仍是试玩值。

## 接入边界

- 纯`FishingRound`仅临时回合；`GameSession`新增cast/land/cancel事务，只有成功落盘才消费鱼获。背包/体力/金币失败回滚，保留caught供重试；临时回合在新游戏、睡觉或成功读档时清空。
- 仍是V6存档，鱼用现有严格ITEMS容器校验；没有新增schema字段或迁移分支，现有V1–V6读档测试保留。旧程序不认识新鱼，因此跨机需同步当前源码。
- `fishingSpot`限制80px内、路径上没有实心障碍的水格；没有修改地图/碰撞/种植规则。
- `FishingPanel`复用PausePanel焦点/菜单暂停，由场景update推进，无额外setInterval/RAF或倒计时timer；后台冻结，恢复首帧丢delta，退出取消并拆监听。世界时钟在钓鱼卡打开时暂停。
- `PondLife`只画水内低对比鱼影/纹波及活动鱼线/浮标和岸边提示，关闭清除鱼线、场景退出销毁。
- 4/3固定逻辑画布在窄窗口按宽度缩放，原格/相机不变；钓鱼卡跨540px断点调整，鱼上岸保留64px展示。暂时设置600×480只用于断点验证，已重置。
