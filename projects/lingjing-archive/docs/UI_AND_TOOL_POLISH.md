原目录55文件851测试、严格类型与86模块生产构建、diff检查通过；面板和空格行为先观察RED。只读审查指出空格默认翻页后补1失败→4通过，最后全量重测。原Phaser大包提示保留。

独立5182新档正常输入，禾木赠种3，南北花草格分别锄地/浇水/播种：体力100→95→90、500金、种子3→2→1，花草转耕地时隐藏。北侧格无姓名遮挡，原始图可直接对比。通过自然路口走森林→农场→镇子，刷新标题继续后体力、种子与耕地保持。最终画面可见北侧单格湿地/种子点。

浇水通知后L暂停5111ms，两张全屏截图SHA相同，关闭后仍见成功提示。最终preventDefault修复后再以“请先开垦这块地”验证5057ms暂停，两图SHA相同；空格正常激活关闭按钮，返回提示与90体力保持。没有因产品新增空格而破坏菜单键盘关闭。最终runtime errors为空。

## 限制与后续

没有强制Canvas或WebGL逐像素分别验收；普通Image有两路径支持，自动测试只证明对象几何/纹理帧契约。Canvas内置roundPixels的半像素绘制属于待实机细查，不宣称完全无重叠。没有强制后台/全季节新实机验证。

画布没有可点击AX元素，webarea点击无法hit-test；工具流程通过正式空格快捷键完成，不能宣称鼠标实测。旧构图阶段的“开垦隐藏未验”已由键盘同处理器补上，鼠标输入本身仍有缺口。

居民常驻姓名在近旁可能覆盖一块地，本次第一格靠近禾木，故补了北侧无遮挡格验证。后续可优化姓名显示时机。更大的美术差距仍是人物/建筑像素密度、色板与其他季节，不继续用面板改动代替专业素材迭代。

独立QA个人档不随源码跨机，不重置用户原试玩入口。截图、SHA与验证记录见`verification/ui-tool-polish-qa.json`。
