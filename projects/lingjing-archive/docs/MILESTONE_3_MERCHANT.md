# M3-B · 禾木与首份收成（2026-10-15）

已完成本地实现与实机验收：农场有第一位原创杂货商禾木、天气/时段/任务状态对话、Q任务手记，以及一条可跨刷新继续的入门委托。不是完整NPC生活系统或商业版完成声明。

## 玩家流程

农田东侧靠近禾木按E交谈。领取当季最短成熟周期作物的种子3颗，开垦、播种、每天浇水，回小屋床边休息。收获后把指定作物放在随身背包，交给禾木1份，获得120金。多余收成保留。委托只可领取/完成各一次，无期限；接取时锁定作物，跨季不改变。春青露萝卜、夏火绒番茄、秋丰叶白菜、冬冰露草。

Q随时查看手记，远处不能领种或交付。对话内可打开已有集市；B集市/I背包入口保留。对话、手记与集市暂停移动和时钟，Esc关闭，Tab选择按钮，Enter确认；地图不会接收到对话中的E/B/I/T/数字键。
