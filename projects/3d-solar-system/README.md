# 太阳系交互模型 · 深空观测图鉴

直接打开 `web/solar-standalone.html`。单文件已包含渲染库、程序化纹理生成代码和交互逻辑，无需安装依赖或启动服务器。

## 本轮画风升级

- 以暖白、铜金与灰蓝重做观测界面，去掉青色霓虹边框与选中光圈。
- 新增离线、可复现的行星色彩与起伏材质：岩质细节、气态行星云带、太阳颗粒；地球使用全分辨率地形与独立海洋粗糙度。
- 细化星环层纹与暗隙，增加行星投射到星环的阴影；修正星环倾角与行星自转轴，使二者持续对齐。
- 用球面边缘散射代替大块光晕，降低星空与轨道的亮度，保留昼夜明暗和可读的暗面。
- 709×632 等较矮窗口改用侧边资料面板，保留手机底部资料布局。
- 材质均为程序化艺术表达，地球大陆也是生成纹理，并非卫星影像或真实地理地图。行星资料沿用原项目，本轮没有重新核定动态天文数据。

## 保留的交互改进

- 用“探索天体”菜单直接选择太阳和八大行星，也可在全景中点击天体。
- 桌面资料显示在右侧，手机显示在底部；镜头将主体放进剩余可见区域，避免资料遮挡。
- 根据有效区域的横竖尺寸与星环半径构图，调整窗口后重新计算。
- 修正高倍速镜头追赶偏差；相机过渡使用真实帧时间，不与模拟步长混用。
- 拖拽支持主指针捕获、取消与失焦复位；非主鼠标键不触发选择。
- 根据已有数据保留逆向自转方向，修正月球朝向；FPS 使用真实帧间隔计算。
- 切至后台时暂停渲染；恢复时避免时间突跳。初始化失败时显示重试入口。
- 网页与单文件版使用同一份本地 Three.js，并校验单文件资源已内嵌。

## 操作

| 操作 | 作用 |
| --- | --- |
| 探索天体菜单 | 直接进入某个天体的近景 |
| 全景中点击天体 | 选择天体并显示资料 |
| 拖拽 | 旋转视角 |
| 滚轮 | 缩放 |
| 暂停或空格 | 暂停与继续 |
| 1×、4×、16× | 设置演示速度 |
| 全景复位 | 退出近景并恢复默认观察角度 |
| 资料右上角关闭或 Esc | 退出天体近景 |

聚焦时减少其他天体的视觉干扰，返回全景后恢复。操作按钮和菜单可通过键盘聚焦；系统偏好减少动态效果时，初始演示保持暂停。

## 源码

`web/solar.html` 是开发入口；`solar-motion.mjs` 包含可独立测试的构图与动画计算，`solar-surfaces.mjs` 生成确定性表面色彩与起伏数据。`solar-standalone.html` 是生成文件，应修改源码后重新构建。

在项目根目录安装原有锁定依赖后运行：

```sh
npm ci
npm run test:solar
npm run build:solar
# 启动网页服务器后，使用本机 Chrome 执行双模式浏览器回归
npm run test:solar:browser
```

模块版需要本地静态服务器，避免 file URL 的模块加载限制。可在项目根目录运行：

```sh
python -m http.server 4321 --bind 127.0.0.1 --directory web
```

然后打开 `http://127.0.0.1:4321/solar.html`。
