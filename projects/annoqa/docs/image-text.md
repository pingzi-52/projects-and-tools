# 图像与文本数据标注规范

## 1. 图像分类标注

图像分类任务的标签体系必须与任务说明一致，不得自行新增标签。遇到任务说明中未覆盖的类别时，在备注中说明情况并提交任务负责人确认，不得直接跳过。

单个类别的判定置信度低于 0.7 的样本，标记为 `uncertain`，交由第二人复核。

## 2. 边界框标注

2D 边界框必须紧贴目标可见外轮廓。框与目标边缘的空隙不得超过 2 个像素，框右下角超出目标的部分不得超过 3 个像素。

## 3. 关键点标注

关键点标注要求点位落在关节中心，误差不超过 3 个像素。不可见的关键点标记为不可见状态，不要猜测位置。

## 4. 文本语料标注

文本数据标注包括意图分类、实体抽取与质量分级三类任务。

- 意图分类：每条语料只分配一个主意图标签。多意图样本在备注中注明次要意图，不重复分配。
- 实体抽取：实体边界以最小完整语义单元为准。例如「北京朝阳区」作为一个地点实体，不拆分为两个。
- 质量分级：按「清晰完整」「轻微噪声」「严重噪声」三级标注。严重噪声的样本直接标注为剔除，不再参与后续流程。

## 5. 数据脱敏

文本中涉及的姓名、电话、身份证号、地址、车牌号等个人敏感信息，标注前必须由脱敏工具处理，标注员不得在标注平台中留存原始敏感信息。

## 6. 多模态对齐样本

图文对样本需同时满足：图像内容与文本描述语义一致、文本描述覆盖图像主要目标、不存在明显的事实错误。三者任一不满足的样本标记为 `misaligned`，不计入有效样本。

## 7. 标注规范冲突处理

当本规范与具体项目的补充规范冲突时，以项目补充规范为准，并向质控组报备。规范中未覆盖的情况，按下列顺序处理：联系任务负责人确认 → 暂缓标注 → 记录到异常台账。
