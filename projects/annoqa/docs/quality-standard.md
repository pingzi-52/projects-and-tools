# 数据质量与交付标准

## 1. 抽检机制

每个批次完成后由质检员抽检，标准比例为 10%。以下情况提高抽检比例：

- 新标注员的前三个批次：抽检比例 30%
- 单批次不合格率超过 5% 的批次：返修后按 50% 抽检
- 重大项目交付前：全量抽检

## 2. 合格率标准

- 一般批次合格率不得低于 95%
- 关键场景数据（如行人、交通标志）合格率不得低于 98%
- 低于上述标准的批次不予交付

## 3. 常见不合格原因

按出现频率排序：

1. 目标边界贴合偏差超出阈值
2. 遮挡或截断标签缺失
3. 类别标签错误（尤其是行人与其他移动目标混淆）
4. 关键点位置偏移
5. 备注缺失导致难以复核

## 4. 交付格式

交付物为 JSON Lines 格式，每行一条样本记录，字段包括样本 ID、原始文件路径、标注结果、标注员 ID、标注时间、质检结论。

字段命名采用下划线风格，时间统一使用 ISO 8601 格式，时区为 UTC+8。

## 5. 数据流转

标准流程为：原始数据接入 → 预处理 → 任务分派 → 标注 → 自检 → 质检抽检 → 返修 → 交付。任一环节出现异常需回流到上一环节，不得跳步。

## 6. 异常处理

遇到规范未覆盖的样本时，标注员应暂停该样本的标注，记录样本 ID 与问题描述到异常台账，由任务负责人统一判定后补充进规范。同一类异常出现 3 次以上的，需在一周内更新规范文档。

## 7. 保密要求

原始数据与标注结果均属公司资产，不得外传。标注员在个人设备上不得留存任何原始数据副本。
